# Daily News AI — Public Data Feed

Automated global news JSON dataset updated hourly via GitHub Actions.

- `data/manifest.json`: Latest batch manifest
- `data/topics.json`: Cross-source major topic timelines
- `analysis_*.json`: Categorized structured news data (`general`, `global`, `tech`, `finance`)
- `data/calendar.ics` & `data/feed.xml`: Public calendar & RSS feeds
